# Data

This directory contains the Elliptic++ dataset used for the ForensicAML project.

* **Source**: Official Elliptic++ dataset release.
* **Labels**:
  * `1`: Illicit
  * `2`: Licit
  * `3`: Unknown
* **Note on Unknowns**: Unknown labels (3) were strictly excluded from the supervised training and evaluation phases.
* **Graph Structure**: Built using the provided transaction network (edgelist).

**Note:** Raw dataset files (`*.csv`) are not committed to this repository due to size constraints.
